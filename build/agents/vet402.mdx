This page is for agent developers whose agents pay x402 endpoints on Celo. vet402 is built by KIZUNA Creation, not by Celo, and it is not a Celo protocol. vet402 buys from listed x402 endpoints, including sellers that settle in USDC on Celo, re-reads each payment on chain, and records whether the paid request returned content. An agent can read that record before it signs a payment.

## Prerequisites

- For the npm package: Node 20 or later and `vet402` 0.1.1 or later.
- For the hosted MCP server: an MCP client that supports streamable HTTP.
- No API key needed. Without a key, `check()` is limited to 10 calls a minute per IP, and the hosted MCP server to 120 requests a minute per IP.

## How it works

1. vet402 pays a listed x402 endpoint, for example one that settles in USDC on Celo, and records the settlement transaction.
2. It records whether the paid request answered 2xx, other than 202 Accepted, with a non-empty body.
3. `check(url)` returns that record with an ALLOW, WARN or BLOCK recommendation, or UNKNOWN when vet402 has no record of the URL. The MCP server's `check_x402_seller` tool returns the same record, with `not_in_catalog: true` when there is none.

## Check a seller from code

```ts
import { check } from "vet402"; // vet402 0.1.1 or later, Node 20 or later

const r = await check("https://api.example.com/v1/quote");
console.log(r.recommendation); // ALLOW, WARN or BLOCK, or UNKNOWN when vet402 has no record of the URL
```

## Connect the MCP server

```json
{"mcpServers":{"vet402":{"type":"http","url":"https://vet402.com/mcp"}}}
```
