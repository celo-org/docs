Celo was created to enable real-world uses cases on Ethereum.

Whether you're building your first app or looking to integrate an existing protocol onto Celo, we have all the resources and tools you need to get started.

---

## Why Build on Celo?

- **EVM Compatibile:** Celo is fully EVM-compatible, offering the same development experience as Ethereum with improved scalability and lower costs.
- **Fast Transactions:** Celo produces **1-second blocks**.
- **Easy, Low-Cost Payments:** Celo's seamless payment infrastructure, including [Fee Abstraction](/build/fee-abstraction/overview), **sub-cent fees**, and **native stablecoins**, enables simple and affordable transactions.
- **Global Reach:** Celo provides access to more than **8 million real-world users** with some apps having more than **200,000 DAUs**.

## Get support

- General questions: join [Discord](https://discord.com/invite/celo), claim the developer role, and ask in `#build-with-celo`.
- Advanced questions: open an issue or join [GitHub Discussions](https://github.com/orgs/celo-org/discussions).
- Longer-form discussion: the [Celo Forum](https://forum.celo.org/).
- Updates: the [Celo Developers newsletter](https://celo-devs.beehiiv.com/subscribe) and [CeloDevs on X](https://x.com/CeloDevs).

Something missing or unclear in these docs? [Open an issue](https://github.com/celo-org/docs/issues/new), or edit the page yourself — the docs live in [celo-org/docs](https://github.com/celo-org/docs), and GitHub will walk you from an edit to a pull request.
