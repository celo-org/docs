<Note>
* Mainnet has been migrated on block **31056500**, March 26, 2025, 3:00 AM UTC.
* The Baklava testnet has been migrated on block **28308600**, February 20, 2025.
* The Alfajores testnet has been migrated on block **26384000**, September 26, 2024.
</Note>

The L1 datadir migration guide has been removed because the tool only produced `op-geth` data. If you wish to run a Celo L2 node from scratch, you can follow the instructions in the [Running a Celo Node](/operate/operators/run-node) guide.
