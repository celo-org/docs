## Mainnet

Celo Mainnet was migrated to an L2 on March 26, 2025, around 3:00 AM UTC, at block *31056500*. For this, the L1 chain was stopped at a block height of *31056499* and the existing state was migrated to work with the L2 nodes. The migration process preserved the full L1 history while updating it to work with the Celo L2 stack. More technical details are available in the [migration docs](/operate/specification/l2-migration).

The Celo L2 network has the following chain properties:

- Block period: 1 second
- Block gas limit: 30,000,000 gas
- Block gas target: 6,000,000 gas (see EIP-1559 elasticity multiplier)
- EIP-1559 elasticity multiplier: 5
- EIP-1559 denominator: 400
- Minimum base fee: 200 Gwei ([Jovian](/operate/specification/upgrades/jovian) `minBaseFee`)

## Celo Sepolia testnet

The Celo Sepolia testnet has the same chain properties as Celo Mainnet, except for a lower minimum base fee:

- Block period: 1 second
- Block gas limit: 30,000,000 gas
- Block gas target: 6,000,000 gas (see EIP-1559 elasticity multiplier)
- EIP-1559 elasticity multiplier: 5
- EIP-1559 denominator: 400
- Minimum base fee: 50 Gwei ([Jovian](/operate/specification/upgrades/jovian) `minBaseFee`)

## OP stack config

| Config                            | Celo        | OP     |
|-----------------------------------|-------------|--------|
| `maxSequencerDrift`               | 2892        | 1800   |
| `sequencerWindowSize`             | 7200        | 3600   |
| `channelTimeout`                  | 50          | 50     |
| `finalizationPeriodSeconds`       | 604800      | 604800 |
| `enableGovernance`                | `false`     | `true` |
| `eip1559Denominator`              | 400         | -      |
| `eip1559DenominatorCanyon`        | 400         | -      |
| `eip1559Elasticity`               | 5           | -      |
| `gasPriceOracleBaseFeeScalar`     | 0           | -      |
| `gasPriceOracleBlobBaseFeeScalar` | 0           | -      |

`channelTimeout` and `maxSequencerDrift` show the values in force. The Granite and Fjord upgrades made them protocol constants: 50 L1 blocks for `channelTimeout`, and 1800 seconds for `maxSequencerDrift`, which Celo's op-node raises by 1092 seconds to 2892 because the sequencer waits for L1 finality. The older configured values (`channel_timeout` 300 in Celo's `rollup.json`, and `maxSequencerDrift` 600 in OP's deploy config) no longer apply.

OP Mainnet can change its EIP-1559 and gas price oracle values in its `SystemConfig` contract, so the OP column leaves them out. OP Mainnet's configuration and `SystemConfig` address are in the [Superchain Registry](https://github.com/ethereum-optimism/superchain-registry/blob/main/superchain/configs/mainnet/op.toml).

The minimum base fee is not part of this config. It is the `minBaseFee` value in the L1 `SystemConfig` contract, encoded in every L2 block header; see [Transaction fees](/operate/specification/transaction-fees#base-fee-floor).
