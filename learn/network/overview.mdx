### Fee currencies

To pay gas in a token other than CELO, set the transaction's `feeCurrency` field. USDC, USD₮ and USA₮ use 6 decimals, so they pass an adapter address as `feeCurrency`, not the token address. The addresses for both networks are on the [fee currency contracts](/build/tools/contracts/fee-currencies) page.
